How to connect

1. Open Settings → Remote (HTTP) on the app.

2. Start the server and scan this QR code.

3. Enter your PIN if remote access is protected.

The server runs on your local network only. Use a PIN on shared or open Wi-Fi.

FAQ

Frequently asked

Is it really free?
Yes. The app is open-source under the MIT license with no ads, no tracking, and no in-app purchases.
Does it support resume?
Yes. Downloads resume automatically after interruption using HTTP Range requests. Partial files are preserved.
Can I control it from my PC?
Yes. Enable the remote server in Settings, then open the URL shown in any browser on the same network.
What platforms are supported for download?
YouTube, TikTok, Instagram, and any direct URL. YouTube uses HLS with audio-video merge. Social media links are auto-detected.
How do I update?
The app checks for new releases on GitHub. Tap "Check for updates" in Settings, then download and install manually.
