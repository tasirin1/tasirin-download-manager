Pindai untuk membuka remote

Cara menghubungkan

1. Buka Pengaturan → Remote (HTTP) di aplikasi.

2. Jalankan server, lalu pindai kode QR ini.

3. Masukkan PIN jika remote access dilindungi.

Server hanya berjalan di jaringan lokal. Gunakan PIN saat Wi-Fi tidak terlindungi atau digunakan bersama.

FAQ

Pertanyaan Umum

Apakah ini benar-benar gratis?
Ya. Aplikasi ini open-source di bawah lisensi MIT tanpa iklan, tanpa pelacakan, dan tanpa pembelian dalam aplikasi.
Apakah mendukung resume?
Ya. Unduhan otomatis dilanjutkan setelah gangguan menggunakan HTTP Range. File parsial tetap disimpan.
Bisakah saya kendalikan dari PC?
Ya. Aktifkan server remote di Pengaturan, lalu buka URL yang ditampilkan di browser manapun di jaringan yang sama.
Platform apa saja yang didukung?
YouTube, TikTok, Instagram, dan URL langsung apapun. YouTube menggunakan HLS dengan merge audio-video. Tautan media sosial terdeteksi otomatis.
Bagaimana cara update?
Aplikasi mengecek rilis baru di GitHub. Ketuk "Periksa pembaruan" di Pengaturan, lalu unduh dan instal secara manual.
