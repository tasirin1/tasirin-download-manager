FAQ

What is remote web control?
The app runs a lightweight HTTP server on your device. You can access it from any browser on the same WiFi network to manage downloads, browse files, and play videos — no app install needed on the controlling device.
Is it safe to install?
Yes. The APK is signed with a verified certificate, and the source code is open on GitHub. Play Protect may show a warning for sideloaded apps — this is normal for any app not distributed through the Play Store.
Does it work on Android TV?
Yes. The remote web interface is mobile-first and D-pad friendly. The app includes a LEANBACK_LAUNCHER intent filter for Android TV launchers.
How do I enable remote access?
Go to Settings (⋮ → Settings) and toggle "Start Server". Set a PIN for security. Then open the shown URL from any browser on the same network.
What download features are supported?
Multi-segment downloads, HTTP Range resume, automatic retry with exponential backoff, mirror fallback, HLS/m3u8 detection, cookie persistence, custom User-Agent, speed limiting, and checksum verification.
